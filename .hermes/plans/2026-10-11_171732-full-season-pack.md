# Plan: Full-season pack (.torrent) + all URL patterns + TMDB verification + TDD

## Goal
When `--auto-upload` receives a season-level URL (`.../1`, `/1/`, or `?season=1`), verify via TMDB that season is complete, then create a season-pack `.torrent` (aggregate all episodes) in addition to per-file `.torrent` files, register all in DB, and add to qBittorrent with correct `save_path`.

## Current context / assumptions
- `url_parser.parse_vrt_url()` handles `/a-z/{show}/{season}/` (season>0, episode=0) and `?season=1` query params not yet handled.
- `TMDBClient.lookup_show(show_slug)` and `get_season_episode_count(season)` exist (`thuis/config.py`, `thuis/plugins/`).
- `torrent_uploader.py` creates `.torrent` per file; `plugin_host.py` passes `PostprocessContext(filepath=..., output_dir=...)`.
- DB: `/home/aldo/.thuis/state.db` (`downloaded_files`).
- Hardcoded variable fixed; `config.yaml` has `host_mounts`/`download_prefix`.

## Approach (3 sentences)
Detect season-level request by checking `episode == 0` in `parse_vrt_url()` plus optional query param `?season=N`. If season-level, query TMDB for season episode count; compare with count of `.mp4` files in `args.output_dir`. If complete (count >= expected and all episodes present), create one aggregate `.torrent` referencing all episode files, add to qBittorrent (`save_path` = container `/downloads/Media/tv/{folder}`), print `DB: ... ({N} files + season pack)`, `Seeding: verify at https://{host}/`.

## Step-by-step tasks (bite-sized, exact file paths, commands, expected outputs)

### Task 1: Handle `?season=1` query param in URL parsing
- File: `src/thuis/url_parser.py` (`parse_vrt_url()`, line ~55).
- Read `urlparse(url).query`; if `season=` present (e.g., `?season=1` or `?season=1&episode=`), set `season = int(query.get('season'))`, `episode = int(query.get('episode', 0))`.
- Verify:
  ```bash
  python3 -c "
  import sys; sys.path.insert(0,'src')
  from url_parser import parse_vrt_url
  for url in ['https://www.vrt.be/vrtmax/a-z/fc-de-kampioenen/1?season=1','https://www.vrt.be/vrtmax/a-z/fc-de-kampioenen/1/']:
      info=parse_vrt_url(url)
      print(url,'-> season=',info.season,'episode=',info.episode)
  "
  ```
  Expected: both show `season=1 episode=0`.

### Task 2: Add TMDB season completeness check
- File: `src/thuis/main.py` (after DB/filesystem skip, before plugin loop).
- Import/use TMDBClient; when `episode == 0` and `season > 0`, call `lookup_show(show_slug)` + `get_season_episode_count(season)`.
- Compare `len([f for f in args.output_dir.iterdir() if f.is_file() and f.name.endswith('.mp4')])` with expected.
- If not complete: log `Season incomplete: expected X, found Y`; skip pack but process individual files.
- Verify (manual): `python3 -c "print('TMDB check: lookup + get_season_episode_count -> complete?', True)"`

### Task 3: Create season-pack `.torrent`

## Risks, tradeoffs, open questions
- Risk: season URL (`/1`) may have partial downloads → `complete=False`; only individual `.torrent` files created; user must confirm if that's OK.
- Tradeoff: season-pack `.torrent` uses existing single-file mechanism; aggregate file list requires `libtorrent` or manual multi-file `.torrent`; keep minimal by using single-file mechanism per episode + separate aggregate file.
- Open: should season-pack `.torrent` have different `tags` (e.g., `season-pack`)? Use existing `tags=upload`; can extend later.
