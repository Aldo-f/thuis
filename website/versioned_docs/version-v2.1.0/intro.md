# What is thuis? (v2.1.0)

**thuis version 2.1.0** represents an important incremental improvement in the thuis series, focusing on stability and compatibility with the evolving VRT MAX platform.

This version built upon the foundation of v2.0.0 with specific enhancements for better reliability when accessing VRT MAX content.

## Key Improvements Over v2.0.0

- **Enhanced VRT API compatibility** - Updated to work with v2.1 of the VRT MAX API
- **Improved error handling** - Better recovery from network interruptions and API changes
- **Updated token refresh mechanism** - More robust session management
- **Bug fixes** - Resolved issues with certain content types and regional restrictions
- **Performance optimizations** - Faster startup and reduced memory footprint

## Core Functionality

Like its predecessors, v2.1.0 continues to provide:

- Secure authentication with VRT MAX using your credentials
- High-quality video downloads with automatic format selection
- Subtitle download capabilities (both embedded and external)
- Metadata extraction and saving
- Flexible output options and file naming
- Resume capability for interrupted downloads

## Target Audience

This version is ideal for users who:
- Want reliable access to VRT MAX content
- Need compatibility with the latest VRT API changes
- Value stability over cutting-edge features
- Are upgrading from v2.0.0 and want improved reliability

For the very latest features and improvements, consider upgrading to v2.1.1 or v3.0.0 when available.
